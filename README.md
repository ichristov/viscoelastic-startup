# viscoelastic-startup

This repository is a reproducibility exercise for a series of Comment papers on exact solutions for start-up (Stokes-type) flows of viscoelastic fluids: each Jupyter notebook regenerates, from scratch, the corrected solution, the erroneous published solution it corrects, and the paper&rsquo;s comparison figure, in a few minutes on Colab. The erroneous published solutions are implemented exactly as printed, clearly marked, and shown to fail against a numerical inversion of the Laplace transform and a finite-difference solution.

## How the papers relate

All of the erroneous solutions come from the same slip: the velocity of a plate set in motion at $t = 0^+$ is $\widetilde U(t)H(t)$, and its time derivative contains $\widetilde U(0)\delta(t)$, which is dropped (when the Fourier sine transform meets a mixed derivative) or hidden in an initial condition (when the steady state is subtracted before an eigenfunction expansion). For a fluid with a retardation time $t_r$ (second-grade, Oldroyd-B), each notebook shows in its section _What problem does the wrong solution actually solve?_ that the erroneous solution is the exact solution for a plate whose start-up jump is ramped on the retardation time, with velocity $[\widetilde U(t) - \widetilde U(0)\mathrm{e}^{-t/t_r}]H(t)$; its Laplace transform is the correct one divided by $1 + t_r s$. For a Newtonian or Maxwell fluid ($t_r = 0$), or a plate started without a jump ($\widetilde U(0) = 0$), the error disappears, which is why reducing a solution to one of these limits does not validate it.
